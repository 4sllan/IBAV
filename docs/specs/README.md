# Specifications

This directory contains technical specifications for changes to the IBAV project.

Specs are created by the Windsurf `/create-spec` workflow and reviewed before implementation.

## Naming convention

- `docs/specs/<feature-name>.md` - the spec
- `docs/specs/<feature-name>-tasks.md` - the task list derived from the spec

## Status

- Draft - spec created, not yet approved
- Approved - spec reviewed and ready for implementation
- Completed - all tasks executed and validated

## Process

1. `/analyze-product` - understand the project
2. `/plan-product` - high-level planning
3. `/create-spec <feature-name>` - detailed spec
4. Review and approve
5. `/create-tasks <feature-name>` - task list
6. Review and approve
7. `/execute-task N` - one task at a time
8. Validate and continue only after explicit approval
